# RPCRAFT SHOP — نسخه اجرایی اولیه

این پروژه یک پایه واقعی Next.js + Supabase است؛ برخلاف نمونه‌های نمایشی، محصولات را از دیتابیس می‌خواند و برای احراز هویت و بارگذاری فایل JAR به Supabase وصل می‌شود. در شروع هیچ محصول ساختگی‌ای وجود ندارد.

## نیازمندی‌ها
- Node.js نسخه 20 یا بالاتر
- یک پروژه رایگان Supabase
- برای انتشار عمومی: حساب میزبانی سازگار با Next.js (مثلاً Vercel)

## اجرای محلی
1. فایل `.env.example` را به `.env.local` کپی کن.
2. در Supabase یک پروژه بساز و مقادیر Project URL و anon/public key را در `.env.local` قرار بده.
3. محتوای `supabase/schema.sql` را در SQL Editor پروژه Supabase اجرا کن.
4. دستورهای زیر را اجرا کن:

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کن.

## تبدیل حساب تو به Owner
1. با فرم ثبت‌نام سایت، حساب خودت را بساز.
2. در Supabase → SQL Editor این دستور را با ایمیل واقعی خودت اجرا کن:

```sql
update public.profiles
set role = 'owner'
where id = (select id from auth.users where email = 'YOUR_EMAIL');
```

این مرحله عمداً دستی است تا هیچ بازدیدکننده‌ای نتواند با ثبت‌نام عادی Owner شود. تنها یک حساب را Owner کن. نقش Owner و تنظیمات خصوصی فقط از دیتابیس مجاز می‌شوند.

## نقش‌ها
- `owner`: مالک اصلی؛ تنظیمات خصوصی، مدیریت کاربران، محصولات و مجوز مدیران.
- `admin`: فقط مجوزهای صریحاً فعال‌شده در `admin_permissions`.
- `seller`: پس از تأیید درخواست؛ امکان ارسال محصول.
- `user`: خرید/دریافت و درخواست فروشندگی.

## موارد امنیتی مهم
- فایل‌های JAR در Storage خصوصی‌اند و URL عمومی ندارند.
- سیاست‌های RLS در دیتابیس دسترسی‌ها را محدود می‌کنند؛ مخفی کردن دکمه در رابط کاربری امنیت محسوب نمی‌شود.
- کلید `service_role` را هرگز در `.env.local` با پیشوند `NEXT_PUBLIC_` قرار نده.
- پیش از فروش واقعی، بررسی فایل JAR، اسکن بدافزار، خرید/دانلود امن، ثبت تراکنش و وب‌هوک درگاه پرداخت باید تکمیل و تست شوند.

## وضعیت این نسخه
پیاده‌سازی شده: رابط فارسی RTL، ثبت‌نام و ورود ایمیلی، پروفایل کاربر، فهرست واقعی محصولات تأییدشده، درخواست فروشندگی، بارگذاری JAR خصوصی برای Owner/Seller، ثبت محصول و صف تأیید، پایه نقش‌ها و سیاست‌های دیتابیس.

نیازمند مرحله بعد: صفحه فراموشی رمز، OTP پیامکی واقعی، پنل کامل صف درخواست‌ها و مجوزهای ادمین، ویرایش/حذف محصولات از پنل Owner، درگاه پرداخت و تقسیم کمیسیون، ایمیل/تلگرام مدیریتی، ثبت خرید و کتابخانه دانلود، قوانین و حریم خصوصی، محدودسازی نرخ و تست امنیتی. هیچ پرداخت یا پیامک واقعی در این نسخه فعال نیست.

## دامنه RpCraft.ir
فعلاً دامنه خریداری نشده است؛ برنامه روی localhost قابل اجراست و بعداً با افزودن دامنه به سرویس میزبانی و تنظیم DNS می‌توان `RpCraft.ir` را متصل کرد. این مخزن به‌تنهایی دامنه را ثبت یا سایت را آنلاین نمی‌کند.
